# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application for recording and displaying personal expenses.

For Week 2, I continued building the Budget Tracker from Week 1. I added a structured expense table, upgraded the expense form, added multimedia content, an interactive details section, and advanced CSS selectors.

## Technologies Used

* HTML5
* CSS3
* YouTube iframe

## Features

### Expense Table

The expense table contains:

* Name
* Amount
* Category
* Date

The table uses HTML elements including:

* `<table>`
* `<thead>`
* `<tbody>`
* `<tr>`
* `<th>`
* `<td>`

Five sample expense records are included.

### Add Expense Form

The form contains:

* Expense name input
* Amount input
* Category dropdown
* Add Expense button

The category dropdown contains:

* Food
* Transport
* Rent
* Entertainment
* Other

Each input has a clear ID that can be used later with JavaScript.

### Multimedia

The project includes:

* A budget tracker image/logo
* An embedded YouTube video

### Interactive Elements

A `<details>` and `<summary>` section was added to provide instructions on how to use the tracker.

The table rows also change background color when the mouse moves over them.

The Add Expense button uses `cursor: pointer`.

### Advanced CSS Selectors

The project uses several advanced CSS selectors, including:

* Descendant selector
* `:nth-child()` pseudo-class
* `:not()` pseudo-class
* `:focus` pseudo-class
* `:hover` pseudo-class
